THEO Kitchen & Bar — Responsive Website Edition

Open index.html in a browser or upload this entire folder to GitHub Pages / static hosting.
Keep styles.css, script.js, site.webmanifest and the assets directory together.

New changes:
• Brand-matched THEO favicon.svg, 16/32px favicon PNG, favicon.ico, Apple-touch icon,
  192px/512px home-screen icons and PWA web manifest.
• Tablet-responsive navigation: accessible dropdown at iPad widths, keyboard dismissal,
  escape key handling, and close on tapping outside.
• Responsive iPad portrait / landscape layout for the hero, story, menu/photo journal,
  music, gallery, footer, contact area and menu/photo popups.
• Phone optimization: readable typography, touch-friendly links and category filters,
  balanced image cards, and 320px-wide phone support.

Original design, branding, menu prices, photos, light animations, 3D photo gallery,
menu filters and all existing sections are preserved.

For easy preview, use the separately provided THEO-Kitchen-Bar-Responsive-Standalone.html
which embeds CSS, JS and pictures into one HTML file.
